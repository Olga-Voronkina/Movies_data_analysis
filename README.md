# Analysis of popular movies

## Description

Analysis of preferences of IMDB website users' regarding movies based on pandas и matplotlib.

## Structure

├── imdb_movies.ipynb       # Jupyter Notebook
├── data/
│   └── imdb_clean.csv      # Data of the top 1000 movies scraped from the IMDB website
├── requirements.txt        # Tools
└── README.md               # Project Description

## Used tools

- Python 3.x
- pandas
- matplotlib
- Jupyter Notebook

## Install

1. Git clone
   https://github.com/Olga-Voronkina/Movies_data_analysis

2. Go to project folder:
   cd Project

3. Install libraries and tools:
   pip install -r requirements.txt

## Analysis includes

- Download data
- Data general describtion
- Cleaning data, transforming data types
- Visualisations of most popular genres, frequency of movies by year of release
- Outcomes
